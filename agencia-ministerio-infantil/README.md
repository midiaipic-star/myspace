# Agência de Produção de Materiais para Ministério Infantil

Este projeto tem como objetivo criar uma agência virtual de inteligência artificial especializada na produção de materiais bíblicos e pedagógicos para o ministério infantil.

A agência contará com agentes especializados em pesquisa bíblica, planejamento pedagógico, criação de aulas, atividades e revisão teológica.

Futuramente, o projeto terá um escritório virtual interativo em estilo pixel art, inspirado nos jogos de Game Boy, onde cada agente será representado em seu espaço de trabalho.
